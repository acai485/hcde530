C5 — Data Analysis with Pandas

I called the TMBD api to pull the first 2 pages of the trending movies data to create a more manageable data analysis basis. I then used pandas to transform the extracted data into a dataframe, emphasizing columns about the media type, average rating, and streaming provider of each title. I started off by implementing the first look checklist to help give a broad mental image of what the data looks like. Then, I used the pandas groupby function to group the rows that share the same provider_name and genre_name to compute the average rating. Lastly, I used pandas to merge the data, matching title+genre rows to title+provider rows (same tmdb_id and media_type) in order to compare which genre has the highest average rating on each platform. I plan on trying something similar for my larger API dataset.
